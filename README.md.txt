# BANK GOOD CREDIT PREDICTION PROJECT

## 1. Project Overview
The Bank Good Credit Prediction project uses Machine Learning techniques to classify bank customers into Good Credit and Bad Credit categories based on their credit-related information.

The main objective is to support better credit risk assessment and assist financial institutions in making informed lending decisions.

## 2. Project Objectives
- Analyze customer credit-related data.
- Perform data cleaning and preprocessing.
- Explore important patterns and relationships.
- Build and evaluate Machine Learning models.
- Identify the most suitable model for credit classification.
- Provide data-driven recommendations for credit risk management.

## 3. Dataset Description
The dataset contains 1,000 customer records with 11 columns, including customer identification, credit balances, credit limits, interest rates, enquiries, and the target variable.

**Target Variable:** `Bad_label`
- 0 – Good Credit
- 1 – Bad Credit

## 4. Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## 5. Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Perform data inspection and exploratory data analysis (EDA).
4. Handle missing values and preprocess the data.
5. Split the dataset into training and testing sets.
6. Build Machine Learning models.
7. Evaluate and compare model performance.
8. Perform hyperparameter tuning.
9. Select and evaluate the final model.
10. Present business recommendations.

## 6. Model Evaluation
Model performance is assessed using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC
- Precision-Recall AUC

Special attention is given to identifying Bad Credit customers because the dataset contains an imbalanced target distribution.

## 7. Expected Outcome
The project aims to develop a reliable classification model that helps identify potential credit risks and supports better-informed banking decisions.

## 8. How to Run the Project
1. Download or clone the project repository.
2. Install the required Python libraries.
3. Place the dataset in the project folder.
4. Open the Jupyter Notebook.
5. Run the notebook cells in sequence.

## 9. Disclaimer
This project is developed for academic and educational purposes. Model predictions should not be used as the sole basis for actual banking or lending decisions.
